### Технологии и архитектура
Проект разработан с использованием следующих технологий:
* **Архитектура:** ASP.NET Core MVC
* **ORM:** Entity Framework Core
* **База данных:** SQLite

### 1. Скачивание проекта
Откройте терминал и склонируйте репозиторий с помощью команды:
git clone https://github.com/antonykhaltin-lab/Versta_test_task.git
После завершения загрузки перейдите в корневую папку скачанного проекта.

### 2. Запуск приложения
Файл локальной базы данных orders.db с настроенными таблицами уже включен в репозиторий. Вы можете запустить проект удобным для вас способом:
 - В Visual Studio: Откройте файл Versta_test_project.slnx и нажмите зеленую кнопку запуска (или клавишу F5).
 - Через терминал: Перейдите в папку с проектом и выполните команду: "dotnet run" (без кавычек). Проект запустится, и в консоли появится локальная ссылка (http://localhost:5261), по которой веб-приложение будет доступно в браузере.
